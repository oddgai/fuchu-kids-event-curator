# 月表示と登録リンク

参照画像をもとに月曜始まりの月表示、前後月切替、イベントのタップで詳細ダイアログを実装する。期間情報とおすすめを色分けし、日付未確定の要確認候補はカレンダー外に置く。
複数日開催は週内の開催日を横長のバーでつなぎ、週・月をまたぐ場合は次の行・月に分割する。前後に続く端は角を落とし、どのバーからも同じ詳細を開く。対象期間と当月内だけに表示し、飛び飛びの開催日の隙間はつながない。重なるイベントは別の段に置き、長いバーを優先して上に配置する。件数に応じて週の高さを広げ、全件を表示する。
不明・未記載の会場、時間、料金、対象年齢等は欄を省略する。ただし日程未確定・条件確認の注意は残す。
Googleカレンダーの登録画面を開くリンクを日程ごとに作る。自動登録は行わない。日時の両端が確定した単日開催のみ時刻付きとし、時刻不明・複数日開催は終日で下書きを開く。終日終了日は翌日（排他的終端）。日付不明はリンクを出さない。
PDF/PNGはクリックなしでも読める詳細一覧を維持する。HTMLは外部ライブラリなしで動作し、イベント由来文字列はエスケープする。
