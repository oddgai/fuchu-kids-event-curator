# 月表示と登録リンク

参照画像をもとに月曜始まりの月表示、前後月切替、イベントのタップで詳細ダイアログを実装する。期間情報とおすすめを色分けし、日付未確定の要確認候補はカレンダー外に置く。
複数日開催は週内の開催日を横長のバーでつなぎ、週・月をまたぐ場合は次の行・月に分割する。前後に続く端は角を落とし、どのバーからも同じ詳細を開く。対象期間と当月内だけに表示し、飛び飛びの開催日の隙間はつながない。重なるイベントは別の段に置き、長いバーを優先して上に配置する。件数に応じて週の高さを広げ、全件を表示する。
不明・未記載の会場、時間、料金、対象年齢等は欄を省略する。ただし日程未確定・条件確認の注意は残す。
Googleカレンダーの登録画面を開くリンクを日程・公演回ごとに作る。ボタン文言は「Googleカレンダーに登録」に統一し、複数リンクの場合は日付と開始時刻をボタンの外に表示する。単日の時間帯・複数回公演・午前午後・タイトル内時刻を抽出し、開場時刻は公演開始と分ける。開始だけ分かるものは終了を仮に1時間後とし、リンクの下に「終了時刻は仮」と明記する（実装時の仮置き）。時刻不明・複数日開催は終日、終日終了日は翌日（排他的終端）。日付不明はリンクを出さない。登録先の場所には既知の会場、説明には公式URLだけを入れる。推定年と仮の終了時刻の注記は画面内で保持する。
詳細の場所は既知の場合に表示する。判定理由・判定根拠は表示せず、実際の参加条件・要確認事項は保持する。出典は出典名のリンクを重複なく表示し、同じURLへの「詳細情報」を追加しない。
終演・終了と明記された時刻は開始と対応させ、別公演として扱わない。日別の時刻が文章中に混在し対応を確定できない場合は、日付と時刻の組合せを補わず終日で開く。
PDF/PNGはクリックなしでも読める詳細一覧を維持する。HTMLは外部ライブラリなしで動作し、イベント由来文字列はエスケープする。
