# タイトルに含まれる開催日の抽出

Issue #21。開催日欄だけでは年が足りない場合、タイトルに明記された開催日を参照する。開催日欄の方が範囲を絞っている場合は、その範囲を維持する。タイトルの日時と整合しない月日や、複数年のどちらとも解釈できる月日には年を補わない。

年がないタイトルは、実装時の仮置きとして掲載日を根拠に開催年を推定する。現在年を一律に使う方法では古い記事が毎年復活するため、採用しない。年の明記を必須にする従来方式では月日が分かるプレーパーク等を表示できないため、推定だと明示する方式とする。

推定対象は、公園の詳細ページにある掲載日、またはルミエール府中の公開APIの掲載日時が取れる告知に限る。開催月日は告知の開催日欄・タイトルから取得し、掲載日の月日を開催日として使わない。掲載日から183日以内の単日開催だけを対象とし、年跨ぎも扱う。曜日が書かれていれば一致を必須とする。掲載日がない・日付が無効・複数日・曜日不一致・整合する年がないものは要確認に残す。
タイトル由来の日付が申込締切・受付開始・募集期間等の案内なら開催日として推定しない。

推定した場合は共通形式の `date_note` に掲載日と推定年を保存する。カレンダーは「仮：」を付けて凡例で説明し、詳細・配布用出力・Google登録の下書きにも推定の注記を保持する。推定した日付で対象期間を判定するため、過去の記事はその掲載年のイベントとして対象期間外に分ける。参加条件や時刻の推測は追加しない。
