# タイトルに含まれる開催日の抽出

Issue #21。開催日欄だけでは年が足りない場合、タイトルに明記された開催日を参照する。開催日欄の方が範囲を絞っている場合は、その範囲を維持する。タイトルの日時と整合しない月日や、複数年のどちらとも解釈できる月日には年を補わない。

年がないタイトルは、ユーザー指定によりページ更新日以降で最初に来る開催月日の年を推定する。更新日当日も含める。2026-10-30更新の11/14は2026-11-14、2026-12-20更新の2/11は2027-02-11。現在年を一律に使わず、更新日時を基準として推定だと明示する。

推定対象は公園・ルミエール府中の単日告知。ルミエールは公開APIの更新日時（modified）を使い、取得できなければ要確認に残す。公園はarticle:modified_timeを優先し、なければ詳細ページの表示日付を使う。時刻付き更新日時は日本時間の日付に変換する。開催月日は告知の開催日欄・タイトルから取得し、更新日の月日自体を開催日として使わない。183日制限は設けず、2/29は次の有効なうるう日まで進める。曜日が書かれていて推定日と合わない場合は、さらに先の年を探さず要確認に残す。基準日がない・日付が無効・複数日の場合も要確認に残す。
タイトル由来の日付が申込締切・受付開始・募集期間等の案内なら開催日として推定しない。

推定した場合は共通形式の `date_note` に基準のページ日付と推定した開催日を保存する。カレンダーは「仮：」を付けて凡例で説明し、詳細・配布用出力・Google登録の下書きにも推定の注記を保持する。推定した日付で対象期間を判定する。参加条件や時刻の推測は追加しない。
